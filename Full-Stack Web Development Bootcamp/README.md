## 📌 Descripción

Este espacio recopila el progreso práctico y las soluciones construidas a lo largo de las más de 62 horas de formación[cite: 1, 2]. El temario abarca desde los fundamentos de la web semántica y el diseño responsivo hasta arquitecturas backend completas, APIs RESTful y aplicaciones frontend con React[cite: 1, 3, 4].

---

## 🛠️ Stack Tecnológico

- **Frontend:** HTML5 semántico, CSS3, Flexbox, CSS Grid, Bootstrap 5, JavaScript moderno (ES6+), manipulación del DOM[cite: 3].
- **Backend:** Node.js, Express.js, plantillas EJS, diseño e integración de APIs RESTful, sistemas de autenticación y seguridad[cite: 3].
- **Bases de Datos:** SQL y PostgreSQL[cite: 1, 3].
- **Librerías / UI:** React.js, React Hooks[cite: 3, 4].
- **Control de Versiones y Despliegue:** Git, GitHub y GitHub Pages[cite: 3, 4].
