## 📌 Descripción

Repositorio dedicado a documentar mi progresión paso a paso a lo largo de las 62+ horas de formación técnica[cite: 1, 2]. Cubre desde fundamentos de maquetación semántica y diseño visual hasta arquitecturas backend completas, bases de datos relacionales y librerías modernas de interfaz[cite: 1, 3, 4].

---

## 🛠️ Stack Tecnológico

- **Frontend:** HTML5 semántico, CSS3, Flexbox, CSS Grid, Bootstrap 5, JavaScript moderno (ES6+), manipulación del DOM[cite: 3].
- **Backend & APIs:** Node.js, Express.js, EJS, APIs RESTful, Autenticación y Seguridad[cite: 3].
- **Bases de Datos:** SQL, PostgreSQL[cite: 3].
- **Librerías & Frameworks:** React.js, React Hooks[cite: 3, 4].
- **Herramientas de Entorno:** Bash, Git, GitHub y despliegue en GitHub Pages[cite: 3, 4].

## 🚀 Cómo Visualizar los Proyectos Localmente

1. Clona el repositorio:
   ```bash
   git clone [https://github.com/PabloConde03/aprendiendo-lenguajes.git](https://github.com/PabloConde03/aprendiendo-lenguajes.git)
```

2.Entra al directorio del ejercicio o proyecto que deseas consultar (por ejemplo, el Capstone de HTML):  
```bash
cd "01. HTML/Project"
```

3. Abre el archivo index.html en tu navegador habitual o usa la extensión Live Server en VS Code.
