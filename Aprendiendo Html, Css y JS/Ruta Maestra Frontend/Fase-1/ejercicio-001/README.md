# Ejercicio 1

## Enunciado
Configuración de documento base con <!DOCTYPE html>, <html lang="es"> y metaetiquetas utf-8.

## Conceptos clave
- <!DOCTYPE html> declara el tipo de documento al navegador.<br>- <html lang="es"> especifica que el idioma principal es español.<br>- <meta charset="UTF-8"> define la codificación de caracteres.<br>- <meta name="viewport"> habilita el diseño responsivo.

## Trampas comunes
- Olvidar el DOCTYPE puede hacer que el navegador entre en modo quirks.<br>- Escribir etiquetas en mayúsculas no es válido en XHTML y es mala práctica en HTML5.<br>- No declarar la codificación puede causar problemas con caracteres especiales (tildes, eñes).
