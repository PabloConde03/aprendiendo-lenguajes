# Ejercicio 6

## Enunciado
Bloques de citas con <blockquote> (atributo cite) y citas en línea con <q>.

## Conceptos clave
- <blockquote> se usa para citas extensas que se separan del flujo normal del texto.<br>- El atributo cite en <blockquote> indica la URL de la fuente de la cita.<br>- <q> se usa para citas cortas en línea y el navegador añade automáticamente comillas.

## Trampas comunes
- Usar <blockquote> para citas muy cortas que podrían ir con <q>.<br>- Olvidar el atributo cite cuando se conoce la fuente original.<br>- Anidar <q> dentro de <blockquote> innecesariamente.
