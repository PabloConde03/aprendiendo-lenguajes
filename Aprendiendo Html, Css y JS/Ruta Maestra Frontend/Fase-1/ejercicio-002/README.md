# Ejercicio 2

## Enunciado
Implementación de SEO básico con <title>, <meta name="description"> y <meta name="robots">.

## Conceptos clave
- <title> define el título que se muestra en la pestaña del navegador y en los resultados de búsqueda.<br>- <meta name="description"> ofrece un resumen del contenido para los motores de búsqueda.<br>- <meta name="robots"> indica a los rastreadores si deben indexar la página y seguir los enlaces.

## Trampas comunes
- Título vacío o demasiado genérico (ej. "Documento sin título").<br>- Descripción muy larga (más de 160 caracteres) o ausente.<br>- Robots configurado como "noindex" por error, impidiendo la indexación.
