# Ejercicio 3

## Enunciado
Jerarquía lógica de encabezados (<h1> a <h6>) para un artículo científico.

## Conceptos clave
- <h1> es el encabezado principal y debe ser único por página.<br>- Los encabezados deben seguirse en orden jerárquico (h1 → h2 → h3...) sin saltar niveles.<br>- <h2> a <h6> estructuran subsecciones de forma descendente.

## Trampas comunes
- Usar varios <h1> en la misma página confunde a las tecnologías asistivas.<br>- Saltar niveles (ej. de <h2> directamente a <h4>) rompe la jerarquía semántica.<br>- Usar encabezados solo por su tamaño visual en lugar de su significado estructural.
