# Ejercicio 4

## Enunciado
Marcado de texto estructurado usando <p>, <hr>, <br> y <span>.

## Conceptos clave
- <p> define un párrafo de texto.<br>- <hr> inserta una separación temática o regla horizontal.<br>- <br> produce un salto de línea dentro de un párrafo.<br>- <span> es un contenedor en línea sin significado semántico propio, usado para estilos o scripts.

## Trampas comunes
- Usar múltiples <br> para separar secciones en lugar de <p> o <hr>.<br>- Usar <hr> solo como decoración visual sin propósito semántico.<br>- Anidar <span> en exceso cuando existen elementos semánticos más apropiados.
