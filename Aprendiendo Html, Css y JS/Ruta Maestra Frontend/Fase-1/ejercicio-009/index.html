Ejercicio 9 - Glosario de Términos Técnicos

Glosario Técnico de Desarrollo Web

DOM (Document Object Model)
Representación en árbol de los elementos de un documento HTML que permite a los lenguajes de scripting, como JavaScript, acceder y modificar dinámicamente el contenido, la estructura y el estilo de la página.
API (Application Programming Interface)
Conjunto de protocolos, rutinas y herramientas que permite la comunicación e intercambio de datos estandarizado entre dos aplicaciones de software independientes.
CSS Box Model
Modelo de caja fundamental en el diseño web que define cómo se calcula el espacio de un elemento en pantalla mediante cuatro áreas concéntricas: contenido (content), relleno (padding), borde (border) y margen (margin).
Asincronía
Mecanismo de ejecución que permite realizar operaciones de larga duración (como peticiones HTTP a un servidor o lecturas de base de datos) en segundo plano sin bloquear el hilo principal de la interfaz.
Framework
Estructura de software conceptual y tecnológica predefinida que proporciona librerías, estándares y herramientas para facilitar el desarrollo rápido y mantenible de aplicaciones.
