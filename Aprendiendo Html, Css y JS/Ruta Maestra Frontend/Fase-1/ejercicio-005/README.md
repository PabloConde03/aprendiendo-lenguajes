# Ejercicio 5

## Enunciado
Enfatizado correcto de texto utilizando <strong>, <em>, <mark> y <small>.

## Conceptos clave
- <strong> indica importancia seria y se.renderiza generalmente en negrita.<br>- <em> indica énfasis o entonación y se.renderiza en cursiva.<br>- <mark> resalta texto para referenciarlo o marcarlo como relevante.<br>- <small> indica texto secundario, como notas al pie o derechos de autor.

## Trampas comunes
- Usar <strong> solo para poner texto en negrita sin importancia semántica.<br>- Usar <em> solo para cursiva decorativa.<br>- Confundir <mark> (resaltado contextual) con <strong> (importancia).
