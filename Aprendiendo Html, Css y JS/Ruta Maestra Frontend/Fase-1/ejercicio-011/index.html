Código en línea

Para iniciar un repositorio local en Git se utiliza el comando git init. En JavaScript, la instrucción console.log() imprime datos por consola.

Bloque de código preformateado

Ejemplo de función básica en JavaScript:

function saludar(nombre) {
  if (!nombre) {
    return "Hola, mundo";
  }
  return `Hola, ${nombre}`;
}

// Llamada de prueba
console.log(saludar("Pablo"));
