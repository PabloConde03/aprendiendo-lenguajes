# 🐘 Aprendiendo PHP

Este módulo contiene todos mis apuntes, scripts de prueba y proyectos desarrollados en PHP. Está estructurado para avanzar desde la sintaxis más pura hasta la integración completa con bases de datos MySQL.

## ⚙️ Entorno de Desarrollo Configurado
- **Servidor Local:** XAMPP (Apache + MySQL)
- **Versión de PHP:** 8.x (Tipado estricto habilitado)
- **IDE:** Visual Studio Code con perfil dedicado (`PHP / Backend`).
- **Depuración:** Xdebug activo e integrado en el editor para análisis paso a paso.

## 📚 Índice Temático

1. [**Sintaxis Básica**](./sintaxis-basica/) ➡️ *Variables, tipos de datos, operadores y estructuras de control.*
2. **Programación Orientada a Objetos (POO)** *(Próximamente)* ➡️ *Clases, herencia, interfaces y traits.*
3. **Bases de Datos con PDO** *(Próximamente)* ➡️ *Conexiones seguras, CRUD y sentencias preparadas.*

## 💡 Notas Adicionales
> Cada subcarpeta contiene sus propios ejercicios autónomos. Si clonas este repositorio, asegúrate de servir la carpeta raíz desde `htdocs` en XAMPP o de utilizar la extensión PHP Server en VS Code (puerto `3000` o `8080`) para previsualizar los resultados en el navegador.
