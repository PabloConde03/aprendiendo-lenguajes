# 100 Ejercicios Prácticos de PHP: De Cero a Full Stack

## Arquitectura del Proyecto

Este repositorio contiene **175 ejercicios prácticos de PHP** organizados en **7 bloques temáticos**, diseñados para llevar al estudiante desde los fundamentos básicos hasta la arquitectura full stack completa.

### Estructura de Carpetas

```
ejercicios-php/
├── Bloque 1 - Arquitecturas web y Sintaxis basica/    # 25 ejercicios
├── Bloque 2 - Estructuras de control/                # 25 ejercicios
├── Bloque 3 - Cadenas y arrays/                      # 25 ejercicios
├── Bloque 4 - Funciones/                             # 25 ejercicios
├── Bloque 5 - Programación y validación de formularios/ # 25 ejercicios
├── Bloque 6 - Formularios y persistencia/            # 25 ejercicios
└── Bloque 7 - Gestión de usuarios/                  # 25 ejercicios
```

### Descripción de Bloques

| Bloque | Temática | Tecnologías | Etiqueta |
|--------|----------|-------------|----------|
| **1** | Arquitecturas web y Sintaxis básica (código embebido) | PHP core, HTML embedding | 🟡 **en proceso** |
| **2** | Estructuras de control | Condicionales, bucles, loops | 🟡 **en proceso** |
| **3** | Cadenas y arrays | Manipulación de strings, arrays | 🟡 **en proceso** |
| **4** | Funciones | Funciones definidas, scope, recursividad | 🟡 **en proceso** |
| **5** | Programación y validación de formularios | Formularios HTML, filtros, validación | 🟡 **en proceso** |

| **7** | Gestión de usuarios | Autenticación, roles, perfiles de usuario | 🟡 **en proceso** |

### Detalle por Bloque

#### Bloque 1: Arquitecturas web y Sintaxis Básica
Ejercicios que fundamentan la sintaxis de PHP, el embezado en HTML y los conceptos básicos de programación procedural.

Ejemplos de ejercicios:
- Hola Mundo y Variables
- Operaciones Aritméticas
- Condicional Simple (if/else)
- Estructura Switch
- Bucle For y While
- Arrays indexados y asociativos
- Funciones personalizadas

#### Bloque 2: Estructuras de Control
Profundización en la lógica de control del flujo del programa con condicionales anidados y bucles complejos.

Ejemplos de ejercicios:
- Operador Ternario y Coalescencia Nula
- Bucle Do-While
- Anidación de condicionales
- FizzBuzz clásico
- Secuencia de Collatz
- Patrón de triángulo

#### Bloque 3: Cadenas y Arrays
Manejo de datos de texto y estructuras de datos collections en PHP.

Ejemplos de ejercicios:
- Funciones de string (strlen, str_replace, substr)
- Explode e implode
- Búsqueda y reemplazo con regex
- Arrays multidimensionales
- Functions array_map y array_filter
- Generación de hash SHA256

#### Bloque 4: Funciones
Creación de funciones reutilizables, manejo de scope y técnicas avanzadas de programación funcional en PHP.

Ejemplos de ejercicios:
- Función con parámetros y retorno
- Funciones anónimas y arrow functions
- Scope de variables (local vs global)
- Variables estáticas
- Paso por referencia
- Funciones recursivas
- Funciones variádicas

#### Bloque 5: Programación y Validación de Formularios
Desarrollo de interfaces interactivas con procesamiento en el lado servidor y validación de datos.

Ejemplos de ejercicios:
- Formularios GET y POST
- Validación de campos obligatorios
- Protección contra XSS con htmlspecialchars()
- Sanitización con filter_input()
- Múltiples formularios en una página
- Validación con expresiones regulares
- Formulario completo con todas las validaciones

#### Bloque 6: Formularios y Persistencia
Gestión del estado en aplicaciones web utilizando sesiones, cookies y persistencia de datos.

Ejemplos de ejercicios:
- Sesiones y variables de sesión
- Cierre de sesión (logout)
- Contador de visitas persistente
- Carrito de compras básico
- Preferencias en cookies
- Persistencia en localStorage
- API de sesión en JSON

#### Bloque 7: Gestión de Usuarios
Sistemas completos de autenticación y autorización para aplicaciones reales.

Ejemplos de ejercicios:
- Registro y login de usuario
- Hash de contraseñas (password_hash/verify)
- Recuperación de contraseña con tokens
- Roles y permisos (RBAC)
- Perfiles de usuario
- Estadísticas y reportes
- Import/Export de usuarios

### Estado de los Ejercicios

Todos los ejercicios están marcados con el estado **"en proceso"** para indicar que forman parte de un aprendizaje activo y continuo. Cada ejercicio incluye:

- ✅ **Comentario descriptivo** en el archivo PHP indicando qué se debe implementar
- ✅ **Estructura lista para ejecutar** inmediatamente
- ✅ **Ejercicios progresivos** de dificultad creciente
- ✅ **Codificación profesional** siguiendo estándares PSR

### Tecnologías Involucradas

- **PHP 8.x** - Lenguaje de programación principal
- **HTML5** - Estructuración de páginas web
- **CSS3** - Maquetación y estilos (mencionado en ejercicios avanzados)
- **JavaScript** - Interacciones frontend (mencionado en ejercicios avanzados)
- **SQL** - Bases de datos (ejercicios Bloque 7)
- **AJAX** - Comunicación asíncrona (ejercicios Bloque 5 y 6)

### Objetivos de Aprendizaje

Al completar todos los 175 ejercicios, el estudiante habrá dominado:

1. Sintaxis básica de PHP y embezzado en HTML
2. Lógica de programación con condicionales y bucles
3. Manejo de strings y arrays estructurados
4. Creación de funciones modulares y reutilizables
5. Procesamiento y validación de formularios web
6. Gestión de estado con sesiones y cookies
7. Autenticación y autorización de usuarios
8. Arquitectura completa de aplicaciones full stack

### Cómo Utilizar

1. Navegar a la carpeta del bloque deseado
2. Ejecutar cualquier archivo `ejercicio-Xx.php` con el servidor PHP integrado
3. Seguir las instrucciones del comentario inicial en cada archivo
4. Probar los resultados y avanzar al siguiente ejercicio
5. Marcar cada ejercicio como completado para hacer seguimiento del progreso
